# Todo List

A tiny Todo list web app built without a framework. Todos are stored in the browser's `localStorage`, and the core list logic is covered by unit tests that run on Node's built-in test runner.

## Getting started

To run the unit tests:

```bash
npm test
```

To open the app locally, serve the `public` directory using any static file server (for example `npx http-server public`) and visit the displayed URL.
